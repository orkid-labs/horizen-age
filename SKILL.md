# horizen-age

horizen-age implements ZK age proofs on Horizen Base L3: a prover demonstrates an age predicate (e.g. ≥18) without disclosing the underlying date of birth. Scored by negentropy, gated by ZenKinetic.

## When to use

Adding privacy-preserving age checks to an application on the Horizen L3 stack.

## Install

```
cargo add horizen-age
```
